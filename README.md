# Кинотеатр — бронирование билетов

Дипломный проект по профессии «Frontend-разработчик»

## Ссылка на проект


## Стек технологий

- **React** — библиотека для построения пользовательских интерфейсов
- **React Router** — маршрутизация
- **Vite** — сборка проекта
- **CSS Modules + CSS** — стилизация
- **API** — работа с бэкендом
- **QRCode.react** — генерация QR-кодов

## Функциональность

- Просмотр расписания фильмов
- Бронирование билетов с выбором мест
- Генерация электронного билета с QR-кодом
- Админ-панель для управления залами, фильмами и сеансами
- Drag&Drop для создания и перемещения сеансов
